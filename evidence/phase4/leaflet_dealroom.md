Leaflet is an open-source JavaScript library that developers use to build interactive maps for desktop and mobile browsers. Its mapping features include tile layers, markers, popups, vector shapes and GeoJSON support. Developers can extend the library with plugins and customise maps through its API, while a community of contributors maintains the project.

Keywords: JavaScript, open source, interactive maps, web mapping, web developers, mobile maps, desktop browsers, GeoJSON, tile layers, WMS, map markers, popups, tooltips, vector rendering, SVG, Canvas, mapping plugins, geographic projections, CSS, keyboard navigation
