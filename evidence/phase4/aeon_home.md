Surface Coverage

## Coverage across every layer of your attack surface.

From the kernel up to the cloud control plane, Aeon gives you visibility and enforcement where attackers actually operate.

- ![](https://aeonsec.io/surface/line-active.svg)


### Hosts & Servers





Detect vulnerable packages, suspicious processes, file changes, user activity, weak configurations, and system drift.

- ![](https://aeonsec.io/surface/line-inactive.svg)


### Containers & Kubernetes





Track images, pods, namespaces, exposed services, and risky RBAC so drift and cluster misconfigurations surface before they become incidents.

- ![](https://aeonsec.io/surface/line-inactive.svg)


### Code & CI/CD





Connect repos, pipelines, secrets, artifacts, IaC changes, and deployment permissions to catch weak approvals and insecure release paths.

- ![](https://aeonsec.io/surface/line-inactive.svg)


### Network





Correlate ports, routes, VPNs, firewall rules, DNS, and east-west paths so exposed traffic and stale access are easier to close.

- ![](https://aeonsec.io/surface/line-inactive.svg)


### External Surface





Monitor domains, IPs, certificates, cloud endpoints, SaaS apps, and shadow assets attackers can reach from the public internet.
